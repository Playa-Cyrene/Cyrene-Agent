# Startup animation assets

`default.mp4` is the Seedance 2.0-generated Cyrene animation supplied by the contributor for this feature. It is the original 1280×720, 24 fps, 15.041667 second silent video; no model, reference images or other source assets are distributed here.

素材提供者声明：默认视频使用 Seedance 2.0 生成，无侵权风险。

音频备注：当前默认视频不含音频，后续版本可能加入音频。

The Windows playback helper is derived from Dragon Codex Boot:
https://github.com/yushua0808-cpu/dragon-codex-boot

Its MIT notice is retained in `LICENSE-DragonCodexBoot`. Changes add Agent launch/attach modes, actual-media-duration playback, settings integration, frame holding, window conceal/restore and client-area alignment. The executable is rebuilt from `scripts/startup-animation/CyreneBoot.cs`; it is not committed as a binary. The helper uses the project's existing tray icon at build time.
