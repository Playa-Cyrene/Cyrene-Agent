# 订阅 OAuth（ChatGPT / Claude / Grok）

用 ChatGPT、Claude 或 Grok 的订阅账号登录，在 Cyrene 中通过本地代理使用订阅模型，无需填写 API Key。

## 1.3.4 更新

- 适配 1.3.0 的多模型渠道：合并旧档案，并保留已有聊天的模型选择与手动配置。
- 配合宿主修复，工具续答按原生调用身份关联，保留搜索与加密推理上下文，避免完整调用被误判为残缺而重复重试；真正残缺的调用仍会被拒绝。
- 配合宿主图片卡片与安全协议，图片预览不再依赖插件端口；支持放大、保存原图与同消息重试恢复。
- 参考图先在本地下载校验再发送，避免上游下载外链超时；权限等不可重试错误立即停止。

**升级要求：**续答解析、图片卡片与安全策略的修复属于宿主，需要同时安装包含这些修复的 Cyrene 版本并重启。仅将插件升级为 1.3.4，不能修复未适配宿主的续答重试和图片预览。原有订阅登录与配置保留，不需要删除插件数据。

## 功能

- 支持 ChatGPT Plus / Pro、Claude Pro / Max、SuperGrok / X Premium+
- 支持多账号登录、切换和凭据更新
- 拉取可用模型、思考档位、上下文长度和订阅用量
- 每个订阅渠道一个档案，同一页管理全部模型及各自的上下文、视觉和推理能力
- 自动合并旧版单模型档案，保留默认模型、旧聊天的模型选择和手动配置
- 支持 Cyrene 工具调用及工具结果续轮
- ChatGPT、Claude、Grok 订阅模型使用各自上游的原生联网搜索，不再消耗或调用 Cyrene 配置的第三方搜索后端
- 使用 ChatGPT 或 Grok Build 订阅生图，并在聊天窗口直接显示轻量预览
- 生图参考图输入、会话内角色资料复用，以及失败重试时的已生成图片恢复
- 按各服务的原生协议转发请求

## 安装与使用

需要 Cyrene **1.3.0 或更新版本**。

1. 在 Cyrene 的插件页选择本插件 ZIP，安装后启用并打开。
2. 选择订阅服务并完成浏览器 OAuth 授权。
3. 点击「查看用量/模型」，再点击「同步模型到渠道档案」。
4. 在宿主模型页打开对应订阅渠道，选择新对话的默认模型；已有聊天可在该渠道下独立切换模型。

升级后，插件会在宿主窗口就绪时合并旧版档案，无需重新登录。添加隐藏模型或手动填写模型 ID 都会追加到同一渠道；再次同步不会清空已有模型。每个模型的上下文长度、视觉开关和手动推理规则分别保存，用户已有配置优先保留。宿主窗口暂不可用时，旧档案会保留到会话绑定迁移成功后再清理。

需要生图时，在 Cyrene「工具」页开启「Chat 模式工具增强」，并在 Chat 页签勾选「订阅生图（ChatGPT / Grok）」。之后直接在聊天中描述想生成的图片即可；当前使用 Grok 订阅模型或点名 Grok 时，工具会走 Grok Build 的原生 Imagine 能力。

已有角色、现实人物或当前角色自身的图片，会引导模型先联网核对资料与参考图，再调用生图工具。本轮用户上传的图片优先作为参考图；同一会话内，角色与版本完全匹配且 7 天内核对过的资料可复用。更换版本或要求重查时会刷新；原创角色或明确要求不联网时可直接生成。

适配过的新宿主会显示独立图片卡片、真实阶段提示，并支持点击放大和「保存原图」。需要同时更新宿主与完整插件包，并重启宿主加载主进程改动；不要只替换个别模块。未包含图片卡片适配的普通 1.3.0 宿主仍返回旧版 Markdown/原图链接，预览可能被宿主安全策略拦截。ChatGPT 最多使用 3 张参考图，Grok 当前最多 1 张。参考图请求会实际传给上游，但是否接受取决于订阅接口；Grok Build 的参考图编辑入口仍需实机验证，拒绝时会明确报错，不会偷偷丢弃参考图。

公网参考图由插件先下载并校验，再以图片数据随生图请求发送，避免 ChatGPT / Grok 服务器下载外链超时。支持 PNG、JPEG、WebP，单张上限 10 MiB，原始图片不压缩。下载失败会明确提示并停止，不会丢弃参考图改成纯文字生图；修正参考图后可重试。

同一条消息点击重试时，只要原图已经保存，就恢复原有结果，不再请求生成。结果不明的超时不会自动重复扣额度；确实想重新生成时，请另发一条消息要求「再画一张」。

模型原生搜索、推理进度与流式心跳会刷新宿主空闲计时；工具已完成后，界面转为等待模型续答，不再停留在「正在执行 update_todo」。ChatGPT 工具续答保留加密推理与原生搜索记录。权限、鉴权、无效请求等不可重试错误立即停止，临时网络或服务故障仍有限重试；错误详情保留上游状态、错误码、脱敏说明和请求 ID。上游权限限制不会被插件绕过。

本地代理首次使用时优先监听 `127.0.0.1:6231`，之后会复用模型档案中上次成功的端口。若该端口被其他软件占用，插件会自动寻找后续可用端口；迁移档案后还会等待宿主窗口就绪，并通过公开 API 同步刷新运行时模型缓存，无需重启、关闭代理软件或手工修改模型地址。

## 权限、网络与数据

- 仅申请宿主的 `secrets` 权限，用于加密保存 OAuth 凭据；凭据不写入明文文件或日志。
- 登录、模型目录、用量查询和对话会连接各服务的官方域名：
  - OpenAI：`auth.openai.com`、`chatgpt.com`
  - Anthropic：`claude.ai`、`console.anthropic.com`、`api.anthropic.com`
  - xAI：`auth.x.ai`、`api.x.ai`、`cli-chat-proxy.grok.com`
- 对话内容只发送给所选服务；插件没有遥测或第三方回传。
- 参考图下载会连接用户上传之外、模型检索选出的公网 HTTPS 图片站点；不携带 OAuth 凭据或 Cookie。每次跳转均校验域名及 DNS 地址，固定连接到已核对的公网 IP，拦截内网、保留地址、非 HTTPS 跳转和超限下载。下载的参考图只在内存中处理，不额外落盘、不写入聊天记录。
- 系统 DNS 返回代理 Fake-IP（`198.18.0.0/15`）时，通过 `cloudflare-dns.com` 做 HTTPS 公网解析核验，仅查询图片站点域名，不发送图片地址的路径、提示词或账号凭据；核验失败仍拦截，不直接放行保留地址。
- 生图原图与压缩预览保存在本地。新宿主接收一份持久副本，聊天记录只保存随机图片 ID，不写入生成图片的 Base64 或磁盘路径；插件停用、代理端口变化不影响这些新图片。
- 旧宿主通过仅监听 `127.0.0.1` 的媒体服务提供原图链接，需要插件继续运行；聊天 Markdown 预览是否显示取决于宿主安全策略。
- 角色参考缓存按会话隔离，保存已核对的外观、来源和参考图地址，不缓存用户上传图片的 Base64。重试记录只保存请求摘要、阶段与随机图片 ID，不保存提示词或 OAuth 凭据。
- 账号标签仅在插件窗口中脱敏显示，主进程日志和状态工具不输出邮箱或 accountId。
- 模型档案通过宿主 API 写入；宿主窗口不可用时会写入 `userData/model-settings.json` 并提示重启。
- 旧档案合并期间会在插件私有目录保存待迁移的会话 ID、档案 ID 和模型 ID，成功后清空；不记录聊天内容或凭据。
- 诊断文件只保留排查所需信息，并移除 token、邮箱及账号、用户和组织标识。

## 注意事项

- 本插件复用各家 CLI 客户端的 OAuth 流程，服务方接口或策略变更后可能需要更新插件。
- Grok 生图取决于账号的 Imagine 权限；免费或 X Basic 套餐不支持，订阅额度和地区限制以 Grok 实际返回为准。
- 请仅使用本人合法订阅的账号，并遵守对应服务条款。
- 跨协议切换模型后建议新建对话，避免历史工具调用格式不兼容。
