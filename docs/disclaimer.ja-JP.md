## 4. Agent の操作と権限に伴うリスク

本ソフトウェアは実験的な Agent ツールであり、セキュリティ保護製品ではありません。モデルの出力、システムのルール、付与された権限に基づき、ファイルの読み書き、コマンドの実行、ブラウザー操作、その他のツール呼び出しを行う場合があります。

大規模言語モデルは、誤った、不完全な、または安全でない出力を生成する可能性があります。また、信頼できないウェブページ、ファイル、メッセージ、ツールの応答によって誤誘導される場合もあります。サンドボックス、権限レベル、承認ダイアログなどの対策はリスクを低減しますが、機器、アカウント、ファイル、データの安全を保証するものではありません。

### 4.1 個別の許可と継続的な許可

承認が必要な操作では、表示された操作内容、対象パス、パラメーター、影響範囲を確認してください。「同意」「許可」などのボタンを押すことは、表示された範囲内の操作を許可することを意味します。情報が不明確な場合、範囲が広すぎる場合、結果を受け入れられない場合は、拒否またはキャンセルしてください。

一部の機能は、保存済みの権限、ツールの有効・無効設定、チャンネル設定、継続的な許可に基づいて動作し、毎回承認を求めるわけではありません。有効なモードと許可範囲を把握してください。以前に操作を許可したことは、その後のすべての操作が安全であることを意味しません。

### 4.2 フルアクセス権限

**フルアクセスはリスクの高いモードです。** 有効にすると、一部の操作では個別の確認を求めなくなる場合があります。Agent が権限の範囲内でコマンドを実行し、ファイルを変更または削除することにより、回復できないデータ損失、システムの異常、その他の不利益が生じる可能性があります。

重要なデータをバックアップし、関連するリスクを受け入れられる機器または隔離環境でのみ使用してください。権限の状態を確認し、不要になったら権限を下げるか、関連機能を無効にしてください。フルアクセスも OS、アカウント、個々のツールの制限を受けます。機器上のすべての権限を持つこと、またはそれらを安全に行使できることを意味しません。

### 4.3 プラグインと外部ツール

プラグイン、MCP サービス、スクリプトなどの拡張機能は、ファイル、ネットワーク、アカウントへ独自にアクセスできる場合があります。その動作とリスクは実装と設定によって異なります。インストールまたは接続する前に、提供元、必要な権限、データの送信先を確認してください。一覧に表示されることや接続できることだけで、安全性の審査が済んでいると判断しないでください。
