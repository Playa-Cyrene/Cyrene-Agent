# 设置页搜索

设置较多时，可在侧栏「返回工作区」下方搜索设置名称或说明，选择结果后跳到所属设置页。能定位的目标会滚动到视野中央，并通过整行或卡片背景闪烁提示位置。

## 检索范围

| 内容 | 检索字段 | 边界 |
| --- | --- | --- |
| 设置项 | 当前界面语言的标题，以及同 key 前缀的 Description / Hint / Desc | 支持 fooTitle 与 fooDescription 配对；按显式登记的命名空间和前缀确定所属页，不合并同名标题 |
| 插件 | 名称、宿主 ID | 不检索插件 description 和插件内部设置 |
| 工具 | 名称、宿主 ID、描述 | 排除 deprecated 非空或全局 enabled 为 false 的工具，与工具面板可见目录保持一致 |
| 技能 | 名称、宿主 ID、描述 | 排除全局 enabled 为 false 的技能；模式开关关闭不等于全局停用 |

匹配忽略大小写和查询首尾空格，使用普通子串匹配。标题前缀、标题或运行时 ID、说明依次排序，同分时短标题优先。组件最多显示 40 条结果，并按设置分区分组。切换界面语言会重新构建静态索引；插件、工具、技能目录在挂载及重新进入搜索时分别刷新，不持续轮询。

## 交互约定

- 空查询不显示任何列表。点击输入框进入搜索态，侧栏品牌、返回按钮、导航和版本信息隐藏；关闭后恢复。
- 小 × 只清空文字，大 × 或 Escape 关闭搜索。方向键切换结果并在结果列表内滚动到可见位置，保留输入焦点，Enter 选择；输入法组合期间不执行这些搜索操作。没有新增 Ctrl/Cmd+F 快捷键。
- 分区各占一个结果卡片，仅首行显示图标，其余行保留对齐空位；名称与说明的命中片段使用粉色标记。颜色沿用现有主题变量。
- 搜索框位移和目标滚动各为 300ms。滚动超出首尾边界时取可到达的位置。系统开启“减少动态效果”时，脚本不执行平移动画或逐帧滚动，直接定位；背景提示仍保留，但不使用 CSS 渐变过渡。
- 定位后背景闪烁三次，每次保持 400ms、恢复 200ms；图片等子元素不施加变灰滤镜。
- 查找、滚动、等待闪烁和闪烁期间，指针按下、滚轮、按键或触摸开始均可中断。新搜索和卸载也会取消前一次定位。

## 定位与生命周期边界

索引表示候选项及其所属页，不是所有可见控件的完整注册表。静态文案过滤排除插值、状态后缀、句末标点和多行段落等内容，但不以标题字符数限制正常的多语言设置名。

运行时卡片必须按 `kind + itemId` 定位，不会退回到同名卡片。普通设置优先按翻译 key 定位；旧面板没有身份标记时，只在可见文本唯一的情况下回退。查找只发生在当前设置内容区，并跳过显式隐藏的元素及其子树。

异步面板的挂载等待最多 5 秒。找到目标后停止观察，滚动结束后闪烁；超时、用户中断或卸载会清理观察器、定时器、动画帧和窗口事件监听器。目录 IPC 没有新增宿主取消接口，旧请求可以继续完成，但其结果会被清理标记忽略，不能覆盖新的目录。

模型运行设置登记了自动展开。未登记的折叠区、条件设置或未显示的模态框可能只有页面跳转，没有目标高亮。工具和技能的 Work / Code / Learn 分页不会自动切换；目标不在当前分页时不闪烁。不要为了产生高亮而定位到另一个同名项。

## 后续维护

- 新增设置分区时，同步维护 `settingsNavItems.tsx` 的导航定义与 `settingsSearchIndex.ts` 的命名空间映射，避免结果指向错误页面。
- 翻译说明应与标题采用相同的路径和 key 前缀，例如 `requestTimeout` 与 `requestTimeoutHint`，或 `autoReadTitle` 与 `autoReadDescription`。直接同名标题优先于补 `Title` 的候选，说明不会按显示文字猜测关联，也不会独立成为结果。工具总开关 `toolPanel.chatEnhanceTitle` / `chatEnhanceDesc` 单独登记，避免收录该命名空间里的模式和状态提示。
- 新增或调整运行时卡片时，保留卡片上的 `data-settings-search-kind` 与 `data-settings-search-id`，值使用宿主身份，不使用展示名称。
- 同名设置的标签应标记 `data-settings-search-key`，使用完整翻译 key。卡片或标签的 DOM 重构应同时检查整行定位范围。
- 折叠区可用 `data-settings-search-reveal` 显式列出允许搜索展开的翻译 key，以空格分隔；当前实现只适配其内部 Ant Design Collapse 的未展开 header。不要把可修改设置的按钮登记为展开入口。
- `SettingsSearch.tsx` 和 `SettingsSearch.css` 的动画时长应保持一致。若改动查找、取消或目录刷新，应补充对应生命周期回归用例。

## 验证方式

```bash
pnpm run check:renderer
pnpm exec vitest run src/renderer/react/features/settings src/renderer/react/i18n
pnpm run build:renderer
```

`SettingsSearch.test.tsx` 挂载产品组件，IPC 使用隔离数据，时钟及滚动几何可控。它验证输入法保护、清空与重入、目录请求隔离、同名/隐藏/延迟目标、展开、滚动边界、三次闪烁、中断及卸载清理。索引用例验证多语言、说明关联、保留同名项及排除范围。模拟测试不能证明真实窗口的像素、动画观感或输入法兼容性。

真实窗口还应逐项检查：

1. 搜索框上下间距、端帽与关闭按钮尺寸，以及进入/退出时的同步性。
2. 分组卡片、首行图标、固定行高、说明对齐和列表末行完整可见。
3. 300ms 位移和滚动的观感，中间项居中与首尾项滚动边界。
4. 三次整行背景闪烁、图片保持原样，以及用户操作立即打断。
5. 真实输入法组合、切换语言、实际插件/工具/技能目录及分页行为。

测试记录应区分自动化结论和人工确认；未逐项执行的视觉检查不能写成全部验收通过。
