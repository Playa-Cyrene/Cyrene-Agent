# 设置搜索

设置页提供标题栏搜索弹窗，可按关键词搜索或按分类逐层浏览。

- 设置页标题栏点击“搜索设置”打开弹窗。
- 支持基础设置、Agent 能力、外部频道、语音能力、使用须知五类筛选。
- 按当前语言的设置名称和所属页匹配，支持多个关键词。
- 搜索历史仅记录关键词搜索；通过分类逐层进入设置项不写入历史。历史保存在本地，最多 30 条，支持单条删除与确认清空。
- 选择结果跳转至设置页并滚动高亮；条件项未显示时提示不可用，不自动修改设置。
- 模型页的高级选项和运行参数在搜索命中时自动展开对应折叠面板；手动收起后再次选择同一结果会重新展开，不保存或修改配置值。
- 新增搜索项需同时更新 settings-search-index.ts 和对应 data-settings-search-id。

验证：node node_modules/vitest/vitest.mjs run src/renderer/react/features/settings src/renderer/react/i18n；node node_modules/typescript/bin/tsc -p tsconfig.renderer.json；node node_modules/vite/bin/vite.js build。

结果展示：同一设置页的名称只显示一次，不再作为每条结果的重复副标题。页面入口保留为可选项；仅命中具体设置时，在该组顶部显示所属页面名称。

分类浏览：保留原结果列表样式，按“大类 → 设置页面 → 具体设置项”逐层进入，每次只显示当前层，返回按钮逐层回退。没有已登记子项的页面直接打开。输入关键词在当前大类或页面范围内直接检索，清空后恢复当前层。关闭重开时回到五个大类。

路径和切换：返回箭头右侧显示完整路径，以反斜杠分隔。进入下一层时项目从右向左进场，返回时从左向右；每项持续 100ms，采用减速曲线，相邻项起始时间间隔 50ms。未访问的行仅保留占位，使用列表视口内的 IntersectionObserver 按需挂载内容；已加载内容保留，滚回时不重播。键盘可加载并滚动到未显示的结果。换层清理旧观察器、重置加载状态；减少动态效果模式下取消动画。

定位提示：具体设置项自身的灰色圆角框变为粉色，粉色变浅再恢复，500ms 完成一次往返，连续播放 3 次（总计 1500ms）后恢复原来的灰色外观。不影响相邻设置、整张分组卡片或内容透明度；标题、页面入口保持原定位提示。

窗口拖动：设置页上方空白区域为拖动区，仅搜索框和窗口控制按钮保留 no-drag 点击区域。

选择焦点：鼠标实际移动到结果上时更新选中项；方向键从当前选中项继续切换，保留搜索框输入焦点并滚动到目标。静止鼠标下的悬停项不产生第二个高亮，也不会因列表滚动抢回选择；鼠标再次实际移动后恢复按鼠标位置选择。分类进入、返回后恢复输入焦点。

审查修正：补录数据目录、网页显示模式；不把统计空状态当设置。弹窗每次打开重新读取决定显隐的引擎、SMTP、记忆模式、高德/搜索开关、Vault 绑定和统计数据存在状态，只保留这些开关及布尔值，不把凭据或设置内容写进索引或历史。读取失败时保留页面入口、隐藏无法确认的条件项。关闭后忽略迟到请求。

定位修正：声明加载状态的面板完成加载后，缺失目标立即提示，不高亮页面标题；仍加载的面板越过三秒继续观察，最多三十秒。未声明加载状态的面板仍用三秒兜底。外部 IPC 切页也会清理搜索目标和提示。
