# 右侧可见浏览器设计规格

## 目标

在 Cyrene 聊天窗口的右侧检查器中提供一个可见的内嵌浏览器，让用户直接浏览网页。首版只做用户操作的浏览器，不接入 Cyrene 的自动化操作。

## 首版范围

- 右侧检查器新增一个可固定打开的“浏览器”标签。
- 提供网址输入、前进、后退、刷新、加载状态和页面标题/地址显示。
- 支持 `http:` 与 `https:` 页面，包括互联网网站和用户已启动的本地服务（例如 `http://localhost:3000`）。浏览器不负责启动项目服务器。
- 页面导航和浏览器控件由 Electron 主进程管理；网页内容由 `WebContentsView` 承载。
- 使用 Cyrene 自己的持久化浏览器会话保存 Cookie 和站点存储，不读取或复用系统 Edge 配置。
- 设置页新增“浏览器控制”标签，首版提供清除 Cyrene 内嵌浏览器 Cookie 的操作。
- 浏览器标签切换或右侧面板收起时隐藏网页视图；重新打开时保留当前页面和登录状态。应用关闭时释放网页视图，持久化会话数据保留。
- 浏览器支持多个临时标签，每个标签独立保留页面、标题、加载状态和导航历史；标签在应用重启后不恢复。

## 不在首版范围

- Cyrene 自动化、页面理解或操作轨迹展示。
- 书签、历史记录、扩展、下载管理、密码同步、Edge 配置导入。
- 应用自动启动或停止项目的本地开发服务器。
- 清除 Cookie 以外的站点数据；首版清理操作不会清除缓存、历史或密码。
- `file:` 页面及自定义协议页面。

## 界面与交互

- 浏览器作为 `RightInspector` 的一个独立标签，与文件树、预览和 Diff 标签并列。
- 浏览器面板顶部提供可横向滚动的网页标签栏和新建标签按钮；每个网页标签可以单独关闭，关闭最后一个标签后保留空白标签。
- 工具栏位于网页视图上方，不被网页内容覆盖；包含地址栏、后退、前进和刷新/停止按钮，操作作用于当前网页标签。
- 地址栏接受 HTTP/HTTPS URL；省略协议时自动补全（公网地址补 `https://`，本机 / 局域网地址补 `http://`，见 `src/main/browser/address-input.ts`）；无效或不支持的协议显示可读错误，不进行导航。
- 当前活动地址和标题随主进程的导航事件更新；加载时展示进度状态。
- 普通网页链接在当前标签打开；`target="_blank"`、脚本新窗口请求、Ctrl/中键点击及链接右键菜单的“在新标签页打开”在应用内创建网页标签。背景标签请求不抢占当前焦点。
- 页面导航失败时保留工具栏，显示错误与重试操作。

## 架构

- 渲染进程负责浏览器标签、工具栏和用户输入，通过受限 preload API 向主进程发送命令。
- 主进程管理网页标签及各自的 `WebContentsView`，负责标签创建、切换、关闭、导航、前进/后退、刷新、加载事件和新窗口策略。
- 渲染进程通过受限 IPC 报告活动网页内容占位元素的位置和尺寸；主进程只显示活动标签的网页视图，将其它标签及未活动面板的网页视图隐藏，避免覆盖其它面板或工具栏。
- 浏览器会话使用独立、持久化的 Electron `Session` 分区，且与 Cyrene 应用页面及系统 Edge 的会话隔离。
- 复用项目已有的右侧面板标签容器；不引入新的浏览器自动化依赖。
- 清除 Cookie 通过专用设置 IPC 调用主进程，只作用于内嵌浏览器的持久化会话。
- 所有网页标签共用内嵌浏览器的持久化会话；清除 Cookie 后刷新所有已打开的网页标签。

## 安全与权限

- 浏览器网页不加载 Cyrene preload，不启用 Node.js 集成；启用上下文隔离、沙箱和网页安全策略。
- 只允许 `http:` 和 `https:` 导航；危险或应用内部协议不得由地址栏加载。
- 首版默认拒绝网页摄像头、麦克风、地理位置、通知等系统权限请求。
- 网页不得访问 Cyrene 的 IPC、工作区文件 API、应用状态或本地文件系统。

## 生命周期与异常

- 主窗口关闭时销毁 `WebContentsView` 和对应 `WebContents`，持久化会话保留。
- 右侧浏览器面板收起时保留各标签页面；应用窗口重建后按标签保存的地址惰性重建网页视图。
- 关闭网页标签时销毁其视图和 `WebContents`；关闭最后一个标签时将其重置为空白标签。
- 浏览器创建失败、地址无效和页面加载失败都应在面板内显示，不影响聊天和其它检查器标签。
- 浏览器内容进程崩溃后提供重新加载入口。

## 验收标准

1. 用户能从右侧面板打开浏览器标签并访问 HTTP/HTTPS 网页和可访问的本地服务。
2. 地址栏、后退、前进、刷新/停止、加载状态和页面标题/地址能随实际导航正确更新。
3. 新建、切换和关闭网页标签时，各自地址、标题、导航历史及加载状态保持独立；目标为后台的新标签不会切走当前页。
4. 普通链接在当前标签打开；新窗口请求、Ctrl/中键点击及链接右键菜单操作在 Cyrene 内打开新标签，不转交系统浏览器。
5. 右侧面板收起、切换到文件预览或调整窗口尺寸时，网页视图不会覆盖其它界面；切回浏览器后活动页面尺寸正确且所有打开页面仍在。
6. 应用重启后，浏览器会话中的 Cookie 和站点存储仍有效；系统 Edge 的会话不会被读取，网页标签本身不恢复。
7. 网页无法调用 Cyrene preload/IPC 或访问本地文件；非 HTTP/HTTPS 导航及系统权限请求被拒绝。
8. 整个首版不向 Agent 暴露浏览器控制工具，也不自动执行网页操作。
9. 设置页的“浏览器控制”中可以清除内嵌浏览器 Cookie，清理成功后显示结果；其它浏览器数据及系统 Edge Cookie 不受影响。
